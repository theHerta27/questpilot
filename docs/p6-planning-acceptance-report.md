## 3. 规划器验证

- 基线：简单、确定性的贪心规划器，可独立端到端运行。
- 优化：带节点数和时间上限的 branch-and-bound。
- 目标：固定候选集内最小期望 AP；相同期望 AP 时选择较少刷取次数。
- Oracle：4 组小型合成问题与穷举结果一致。
- 降级：达到搜索上限时返回经过确定性验证的 best-so-far，并明确标记降级原因。
- 边界：未覆盖材料返回“无已验证路线”；资源或截止日期不可达时返回明确状态。
- 模型边界：DeepSeek 不参与掉率估计、材料计算或路线数值优化。

单目标真实数据抽查：伊阿宋技能一 8→9，在 13 个候选关卡内得到 931 AP、45 次，搜索 8,411 个节点，未触及上限，结论为固定候选集局部最优。
