# 3 分钟演示脚本

1. 用“蓝呆”搜索阿尔托莉雅，展示中文名与别名统一解析。
2. 选择技能一，从 1 级提升到 6 级，先以零库存计算材料缺口。
3. 修改其中一个材料库存并重新核算，指出缺口恒为 `max(需求-库存, 0)`。
4. 输入当前 AP 与黄金果实，生成路线；强调数据版本、样本量、候选范围和“局部最优”声明。
5. 把 AP 降到很小后重新规划，展示不越界的 partial 降级方案。
6. 打开 Trace / Replay，展示 LangGraph 节点事件、Checkpoint、工具摘要、验证结果和版本输入。
7. 最后说明：FakeModel 与真实 OpenAI 兼容模型走同一 Gateway，所有工具走同一 Registry；没有全量数据时系统明确拒绝猜测。
